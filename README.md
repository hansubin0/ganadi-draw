# 🐶 가나디 정확하게 그리기 (Ganadi Draw)

3초 동안 가나디 얼굴을 기억한 뒤, **최대 10획** 안에 똑같이 그려 정확도를 측정하는 모바일 최적화 웹 미니게임사이트입니다.

🔗 **사이트 바로가기:** https://ganadi-draw.vercel.app

---

## ✨ 주요 기능

* **3초 미리보기 & 10획 제한 드로잉**
  * `START` 버튼을 누르면 하단 텍스트를 제외한 가나디 얼굴이 3초간 표시된 후 사라집니다.
  * 최대 10획까지 그릴 수 있으며, 10획을 모두 사용하거나 `바로 채점하기` 버튼을 누르면 즉시 채점됩니다.
* **크기·위치 무관 비율 기반 정확도 채점**
  * 캔버스 구석에 작게 그리더라도 그린 영역(Bounding Box)을 자동으로 추출해 $64 \times 64$ 격자 중앙으로 비율을 유지하며 정규화합니다.
  * **양방향 Chamfer Distance** 알고리즘을 적용해 선의 정밀도(엉뚱한 영역 덧칠 방지)와 재현율(눈·코·입·귀 누락 감점)을 동시에 계산합니다.
* **20단계 등급별 멘트 & 정답 겹쳐보기**
  * `0%`부터 `95% 이상`까지 5% 단위로 세분화된 20가지 재치 있는 결과 멘트를 제공합니다.
  * 결과 화면에서 사용자가 그린 그림의 크기와 위치에 맞춰 반투명 정답 선화를 겹쳐 비교할 수 있습니다.
* **실시간 TOP 100 랭킹 & 개인 최고 기록 관리**
  * 브라우저별 고유 식별자(`localStorage` 기반 UUID)와 Supabase RPC 함수를 연동하여, 동일 닉네임 사용자 간 기록 충돌 없이 기기당 최고 점수만 갱신됩니다.
  * 전체 도전자 수 대비 내 실시간 순위(`전체 N명 중 M위`)를 즉시 확인할 수 있습니다.
* **결과 카드 이미지 저장 및 공유**
  * Offscreen Canvas를 이용해 닉네임, 그린 그림, 정확도, 순위, 등급 멘트가 포함된 결과 카드를 PNG 이미지로 생성하며, 모바일 공유 시트(`Web Share API`)와 PC 다운로드를 모두 지원합니다.

## 🛠️ 기술 스택

* **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS
* **Graphics & Input:** HTML5 `<canvas>`, Pointer Events API (멀티터치 방지 및 모바일 스크롤 잠금 적용)
* **Database:** Supabase (PostgreSQL, Row Level Security, PL/pgSQL RPC)
* **Hosting & CI/CD:** Vercel (GitHub 연동 자동 배포)

## 📁 프로젝트 구조

* `index.html` — UI 레이아웃, 드로잉 캔버스, 전처리 및 채점 알고리즘, Supabase 랭킹 연동, 결과 카드 생성 로직을 포함한 단일 파일 애플리케이션
* `ganadi.png` — 채점 기준 및 3초 미리보기용 원본 기준 이미지
